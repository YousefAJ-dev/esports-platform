# Esports Event & Performance Tracking Platform

Capstone project for event management, performance analytics, and role-based access control.

## Tech Stack
- Backend: Node.js
- Database: PostgreSQL
- Infrastructure: AWS EC2 (Ubuntu)

# Frontend

## Public Facing Website
- View events
- View schedules
- View teams
- View matchups/brackets
- Optional ticket/order interest later

## Log-in / Management
- Admins manage everything
- Organizers create events/sessions and assign teams
- Team Managers manage their own team roster
- Analysts view stats/reports
